# Mystery Delivery System

Python assignment for simulating a delivery system.

## What it does

- Reads delivery data from `data.json`
- Finds the nearest agent for each package
- Calculates delivery distance using Euclidean distance
- Keeps track of packages and total distance for each agent
- Calculates efficiency
- Saves the final result in `report.json`

## Files

- `main.py` - main program
- `data.json` - input data
- `report.json` - output report
- `test_delivery.py` - basic tests
